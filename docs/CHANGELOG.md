# Changelog

Changes to ATK-CL.

This changelog uses manually maintained entries. Release dates and additional details should be added by the author.

## [0.1.0] — first baseline

The project's first recorded baseline version.

- Added the `ATK-SC-1` stream-transformation core.
- Added `ATK-KDF-1` master-key derivation.
- Added internal key separation through `ATK-KS-1`.
- Added integrity-tag generation and verification through `ATK-INT-1`.
- Added the standard version 1 container and the hidden container.
- Added the interactive CLI.
- Added KDF, statistics, benchmark, and avalanche-difference research tools.
- Added integration tests and known-answer vectors.

Status: Experimental / Not cryptographically validated.
